# V1 — Miljø og bærekraft

> Denne filen er en godkjent arbeidsversjon. Den erstatter ikke det kanoniske kapitlet før endringen er flettet inn og loggført. Bruk ID-ene under når tekst skal kommenteres, siteres eller revideres.

## Referansenøkkel

- `V1` = kapittel V1
- `P1` = avsnitt 1
- `S1` = setning 1 i avsnittet
- `T1-R1` = tabell 1, rad 1

## Godkjent tekst

### V1-P1 — Hovedbidrag

<a id="v1-p1-s1"></a>**[V1-P1-S1]** Prosjektets viktigste bærekraftsbidrag er bedre bruk av ressurser i bygg.

<a id="v1-p1-s2"></a>**[V1-P1-S2]** Det treffer særlig FNs bærekraftsmål 12.2 om effektiv bruk av naturressurser.

<a id="v1-p1-s3"></a>**[V1-P1-S3]** Det kan også treffe 12.5 dersom pilotene måler ombruk, reparasjon, utsatt utskifting og redusert materialbruk eller avfall.

### V1-P2 — Mekanismen

<a id="v1-p2-s1"></a>**[V1-P2-S1]** VERIFIED skal ikke telle flest mulig bærekraftsmål.

<a id="v1-p2-s2"></a>**[V1-P2-S2]** Et bedre beslutningsgrunnlag i tilbudsfasen kan gjøre det mulig å sammenligne alternative løsninger, blant annet nyanskaffelse, vedlikehold, reparasjon, rehabilitering og ombruk.

<a id="v1-p2-s3"></a>**[V1-P2-S3]** Prosjektet skal måle hvordan grunnlaget påvirker valgene, ikke forutsette at én løsning alltid er best.

### V1-P3 — Mulighetsrom for klima

<a id="v1-p3-s1"></a>**[V1-P3-S1]** Norske kilder peker på at tidlige materialvalg kan gi et betydelig mulighetsrom for å redusere klimagassutslipp uten å øke prosjektkostnaden.

<a id="v1-p3-s2"></a>**[V1-P3-S2]** Dette brukes som et mulighetsrom, ikke som et løfte om effekt fra VERIFIED.

<a id="v1-p3-s3"></a>**[V1-P3-S3]** Prosjektet skal teste om en forklarbar modell faktisk gjør slike avveininger lettere i praksis.

### V1-P4 — Målt og beregnet effekt

<a id="v1-p4-s1"></a>**[V1-P4-S1]** Prosjektet skal sammenligne resultatene mot en definert baseline.

<a id="v1-p4-s2"></a>**[V1-P4-S2]** Noen resultater kan måles direkte i pilotene, som tidsbruk, forståelse og endring av valg.

<a id="v1-p4-s3"></a>**[V1-P4-S3]** Andre virkninger, som framtidige utskiftninger, klimagassutslipp og livsløpskostnader, må beregnes ut fra dokumenterte forutsetninger.

### V1-T1 — Effektmåling

| ID | Effektområde | Målepunkt i piloten | Sammenligningsgrunnlag |
| --- | --- | --- | --- |
| **[V1-T1-R1]** | Klimagassutslipp | Beregnet CO2 per funksjonell enhet eller bygningsdel | Valgt løsning mot ett eller flere reelle alternativer |
| **[V1-T1-R2]** | Ressursbruk | Materialmengde, forventet levetid og antall beregnede utskiftninger | Nyanskaffelse mot reparasjon, rehabilitering eller ombruk |

### V1-P5 — Feil og omarbeid

<a id="v1-p5-s1"></a>**[V1-P5-S1]** Prosjektet skal undersøke om bedre dokumentasjon kan redusere risikoen for feil og omarbeid.

<a id="v1-p5-s2"></a>**[V1-P5-S2]** I prosjektperioden måles dokumentasjonsmangler og eventuelle observerbare avvik.

<a id="v1-p5-s3"></a>**[V1-P5-S3]** Faktisk effekt på reklamasjoner og langsiktige byggskader kan ikke fastslås uten lengre oppfølging.

### V1-P6 — Sirkulærøkonomi

<a id="v1-p6-s1"></a>**[V1-P6-S1]** Utlysningen har en egen prioritering for sirkulærøkonomi: løsninger for økt ombruk, reparasjon eller deling av knappe ressurser.

<a id="v1-p6-s2"></a>**[V1-P6-S2]** VERIFIED kan treffe denne prioriteringen dersom ombruk, vedlikehold, restlevetid og redusert materialbruk blir reelle alternativer og målepunkter i pilotene.

### V1-P7 — Do-not-harm

<a id="v1-p7-s1"></a>**[V1-P7-S1]** Prosjektet skal også teste mulige negative sideeffekter.

<a id="v1-p7-s2"></a>**[V1-P7-S2]** Lavt klimagassutslipp skal ikke alene gi et alternativ høy vurdering dersom levetid, fuktrobusthet, vedlikeholdsbehov eller dokumentasjonskvalitet er svak.

<a id="v1-p7-s3"></a>**[V1-P7-S3]** Ombruk og reparasjon skal bare vurderes som positive alternativer når teknisk egnethet, restlevetid, transport, ansvar og faktisk materialbesparelse kan dokumenteres.

## Åpne porter før innfletting

- `[EBA_NO2023]` og `[KD2024]` må primærverifiseres før de bærer klimapåstanden.
- Produktkategorier og funksjonell enhet må avklares.
- Analyseperiode for livsløpskostnader må fastsettes.
- Baseline, datakilde og måleansvarlig må defineres for hvert effektområde.
- Pilotene må inneholde reelle alternativer for reparasjon, rehabilitering eller ombruk dersom delmål 12.5 skal brukes.
- Endringen må føres i endringsloggen når teksten flettes inn i det kanoniske kapitlet.
