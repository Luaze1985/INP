# Avgrenset overflatepass for VERIFIED v0.6

**Dato:** 2026-08-05

**Tidsramme:** 2–3 timer

**Målfil:** `../soknadstekst-samlet-kandidat-v0.6.md`

**Styringsregister:** `2026-08-05-tilbakemeldingsregister-v0.6.md`

## Formål

Heve v0.6 tydelig før partnerlesing. Passet skal gjøre teksten mer konkret,
mer menneskelig og mer konsistent. Det skal ikke avgjøre forskningsmetode,
kildestatus, nye datadimensjoner, partnerforpliktelser, arbeidspakker eller
budsjett.

## Før start

1. Les `AGENTS.md`, `CONTEXT.md`, `INDEX.yml` og prosjektbeskrivelsens
   `README.md`.
2. Les v0.6, K3-sannhetsserum v0.6, språkporten og hele
   tilbakemeldingsregisteret.
3. Kontroller arbeidskopien. Ikke bland inn `.agents`, nettside, kanoniske
   K/V-filer eller brukerens øvrige endringer.
4. Kjør Source Guard på målfilen og noter utgangspunktet.

## Tillatte endringer

### Sammendrag og K1 – 25 minutter

- Konkretiser hva prosjektet skal utvikle, koble, teste og måle.
- Beskriv partnertyper uten å bekrefte navn eller roller.
- Beskriv målgruppen og produksjonsnær arbeidshverdag forsiktig.
- Beskriv kundens behov for sammenligning utover pris på en respektfull måte.
- Koble behovet til klima, ressursbruk, levetid og feilrisiko uten å påstå
  dokumentert VERIFIED-effekt.
- Flytt eller fjern den samlede løsningsbeskrivelsen fra K1.

### K2 og K3 – 25 minutter

- Samle hva VERIFIED skal gjøre under K2 og bruk «beslutningsstøtte».
- Ta med Reduzer med positivt dokumenterte funksjoner dersom kildestatusen
  tillater akkurat den formuleringen.
- Fjern avsnittet som forsvarer skillet mellom VIBS og FoU-laget.
- Erstatt «opplysninger» med «datakilder og informasjonsfelt».
- Beskriv valg av relevante parametere og datakvalitet som noe prosjektet skal
  undersøke.
- Fjern «Avgrensning før tildeling».

### K4 – 30 minutter

- Beskriv en trinnvis utviklings- og utprøvingsprosess uten å navngi en
  uavklart formell forskningsmetode.
- Erstatt «bruker» med entreprenør eller kunde.
- Gjør testområdene foreløpige og åpne for faglig utforming med konsortiet.
- Kort ned forskningsetikk og datahåndtering til det som er nødvendig for
  datatyper, ansvar, samtykke/personvern og sporbarhet.

### V1 og V2 – 35 minutter

- Navngi VERIFIED-modellen når påvirkning på løsningsvalg omtales.
- Fjern gjentakelser i klima- og mekanismeavsnittene.
- Fjern kommentarer om hva utlysningen prioriterer.
- Skriv do-no-harm-reglene direkte og reduser gjentatte «skal ikke»-former.
- Avgrens følsomhet til sentrale vekter, forutsetninger og datamangler.
- Avgrens kjemikalie- og sosialsporet til undersøkelse av tilgjengelig
  dokumentasjon og synlige mangler.

### V3 – 15 minutter

- Fjern eller integrer «Hovedavgrensning».
- Bevar økonomiske mekanismer som anskaffelseskostnad, livsløpskostnad,
  tidsbruk og mulige kostnader ved avvik.
- Ikke avgjør endelig V3-overskrift uten Lars. Flagg valget mellom
  «Økonomiske virkninger» og «Praktiske og økonomiske virkninger».

### Kontroll – 30 minutter

1. Kjør alle fem pass i `../../../sintef/internt/sprakport-v0.6.md`.
2. Kjør `python tools/source_guard.py scan --path <målfil>`.
3. Kontroller at F1–F6 og sentrale begreper samsvarer med K3-sannhetsserumet.
4. Kontroller at ingen prosentsats, partnerstatus, kildeoppgradering eller
   metodebetegnelse er lagt til uten godkjenning.
5. Les hele teksten sammenhengende og fjern gjentakelser og selvinstruksjon.
6. Lag en kort resultatrapport med endret, parkert og fortsatt åpent.
7. Oppdater PDF-kandidaten først etter bestått kontroll.

## Blokkerte endringer

- ingen 80–90-prosentpåstand om små bedrifter uten kontrollert original;
- ingen leverandørsoliditet eller konkursrisiko som nytt kriterium;
- ingen ny formell forskningsmetode eller detaljert testprotokoll;
- ingen nytt bærekraftsmål;
- ingen partnernavn eller bekreftede roller;
- ingen arbeidspakker, budsjett eller gjennomføringsplan;
- ingen gjenåpning, oppgradering eller omskriving av sperrede kilder;
- ingen innfletting i kanoniske K/V-filer eller nettsiden.

## Leveranser

1. Oppdatert `soknadstekst-samlet-kandidat-v0.6.md`.
2. `reviews/2026-08-05-v0.6-overflatepass-resultat.md` med kort diff- og
   kontrollrapport.
3. Oppdatert `output/pdf/soknadstekst-samlet-kandidat-v0.6.pdf` etter bestått
   tekst- og kildekontroll.

## Akseptansekriterier

- V0.6 er tydeligere om faktisk aktivitet og målgruppe.
- K1 beskriver problemet; K2 samler løsningen og nyhetsverdien.
- Teksten inneholder ingen intern selvinstruksjon eller KI-dialog.
- Metode og testdesign framstår som troverdige arbeidsretninger, uten falsk
  faglig ferdigstillelse.
- Alle nye eksterne påstander har tillatt bevisrolle.
- Source Guard gir null treff.
- Lars får en eksplisitt liste over beslutninger som fortsatt gjenstår.
