# VERIFIED IPN - strategi for sammensetning

## Formål

Bygge én kort søknadstekst fra flere dokumenter uten å blande arbeidsnotater, gamle påstander og verifiserte kilder.

## 1. Dokumenthierarki

1. **Kildekritisk kontrolldokument v0.2** styrer hva som kan brukes, hva som må tones ned og hva som er blokkert.
2. **Kanonisk kildedom og kildebibliotek** styrer kildeport, provenans og status. De skal ikke omskrives i skrivepasset.
3. **K/V-kapitlene** er råmateriale for søknadsteksten.
4. **Eldre dokumenter** brukes bare som spor til begreper, tidligere valg, tall eller argumenter. De er ikke fasit.
5. **Blueprinten** styrer rekkefølge og enkelt språk, men inneholder ikke kildekontroll.

## 2. Gammel og ny tekst

- Behold gammel tekst når den beskriver prosjektets idé, FoU-spørsmål eller avgrensning og ikke motsies av nyere kontroll.
- Erstatt gammel tekst når kilde, tall, begrep eller prosjektstatus er endret.
- Ikke lim sammen to versjoner. Skriv én ny formulering fra den nyeste kontrollerte forståelsen.
- Ta vare på gammel tekst i arkiv eller historisk dokument, ikke i søknadsprosaen.

## 3. Kildebalanse i teksten

- Norske/offisielle kilder først for norske forhold, regelverk, marked og bygg.
- Fagfellevurdert forskning for metode og generelle mekanismer.
- Interne SINTEF-/VIBS-notater brukes som arbeidsgrunnlag og spor, aldri som uavhengig bevis.
- Gule kilder brukes bare med tydelig forbehold. Røde og parkerte kilder skal ikke bære søknadstekst.
- Ett tall skal ha én tydelig kilde og én avgrenset betydning.

## 4. Sammensetningsrekkefølge

1. Bakgrunn og utfordring (K1)
2. Mål og FoU-spørsmål (K3)
3. Hva som finnes i dag og gapet (K2)
4. Metode og forskningsusikkerhet (K4)
5. Bærekraft og ressursbruk (V1)
6. Sikkerhet og ikke-skade (V2)
7. Virkninger og økonomi (V3)
8. Arbeidspakker og gjennomføring når de er avklart

## 5. Samlet språkregel

Skriv hva prosjektet **skal undersøke, utvikle og måle**. Skriv ikke at VERIFIED allerede har gitt effekt. Bruk forklarbare ord fra blueprintens ordliste.

## 6. Sluttkontroll før prosatekst

- Ingen kilde fra gamle dokumenter er flyttet inn uten statuskontroll.
- Ingen påstand har sterkere ord enn kilden tåler.
- Hovedspor, målepunkt og FoU-usikkerhet henger sammen.
- Kildekontroll ligger i kontrolldokumentet; søknadsteksten holdes ren.
