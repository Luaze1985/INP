# ipn-verified

IPN-søknaden **VERIFIED** til Norges forskningsråd — eget prosjekt, skilt ut fra VIBS-produktappen `vibs-boligpass/` 2026-06-28.

Dette repoet inneholder søknadstekst, kilder, kildeverifisering og styringsdokumenter. Det inneholder **ikke** produktkode (plattform, UI, pilot, nettside) — det ligger fortsatt i `vibs-boligpass/`.

## Start her

1. `AGENTS.md` — regler, roller, kilde-/sannhetsprinsipper.
2. `CONTEXT.md` — hvor søknaden står nå og hva som gjenstår.
3. `INDEX.yml` — full filoversikt.
4. `IPN-FLYTTES.md` — status på utskillingen (hva er kopiert, hva gjenstår).
