# K3 — Mål og FoU-spørsmål

**Status:** første røffe utkast · **Sideanslag:** ~1,5 · **Vurderes under:** Kvalitet  
**Forelder:** `ipn-hovedokument.md` §2 · **Forankring:** SoA §12

## Søknadstekst

Hovedmålet er å utvikle og teste en forskningsbasert beslutningsmodell for material- og
produktvalg i små og mellomstore byggeprosjekter.

Modellen skal gjøre det mulig å sammenligne pris, klima, levetid, vedlikehold, dokumentasjon
og risiko før valget tas. Den skal også vise når grunnlaget er godt, når det er svakt, og når
det mangler data.

Prosjektets FoU-bidrag ligger ikke i å lage en enkel poengformel alene. Det ligger i å finne
ut hvordan vekting, usikkerhet og faktisk bruk kan dokumenteres og prøves i praksis. VERIFIED
skal derfor teste både modellen og om folk faktisk forstår og bruker den.

Prosjektet samles i seks FoU-spørsmål:

| Nr. | FoU-spørsmål | Hva prosjektet skal finne ut |
| --- | --- | --- |
| F1 | Kvalitet og levetid mot økonomi | Kan bedre dokumentasjon av levetid, vedlikehold og kvalitet brukes som grunnlag for mer lønnsomme og bærekraftige valg? |
| F2 | Data tidlig nok i tilbud | Kan NOBB, GTIN, EPD, FDV og prisdata kobles slik at de kan brukes før tilbudet sendes? |
| F3 | Ombruk, reparasjon og rehabilitering | Kan modellen vise når ombruk, vedlikehold eller rehabilitering er bedre enn nytt kjøp? |
| F4 | Forståelse og beslutning | Forstår SMB-entreprenører og kunder grunnlaget, og påvirker det valget de tar? |
| F5 | Byggdata mot bank og forsikring | Kan byggteknisk dokumentasjon gi bedre grunnlag for grønn finans, forsikring eller takst uten personprofilering? |
| F6 | Sporbarhet og skalering | Kan dataflyt, API-er og dokumentasjon bygges slik at modellen kan etterprøves og brukes i flere produktkategorier? |

Arbeid før innsending er avgrenset til konsept, problemanalyse, kildesjekk og søknadsarbeid.
Selve FoU-aktivitetene starter etter innsending og eventuell tildeling. VIBS-plattformen brukes
som testflate, men forskningsarbeidet er VERIFIED-laget: metode, datakvalitet, vekting,
usikkerhet og målt beslutningseffekt.
