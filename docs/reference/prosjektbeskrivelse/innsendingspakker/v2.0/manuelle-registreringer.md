# Manuelle registreringer - VERIFIED v2.0

**Status:** Arbeidsmal. Video-uttrekk, ikke manuelt verifisert mot alle levende
portalvalg. Feltnavn, valg og flyter skal kontrolleres før registrering.

Denne filen inneholder opplysninger som må velges eller registreres i portalens
menyer. Den er ikke innlimingstekst.

## Kvalifisering

- `FORETAK I VANSKELIGHETER` - obligatorisk valg.
- `HAR DERE MED MINST ÉN SAMARBEIDSPARTNER ELLER FoU-LEVERANDØR?` -
  obligatorisk valg.
- `MOTTAR ALLEREDE ANNEN OFFENTLIG STØTTE?` - obligatorisk valg. Videoen viste
  en stoppmelding ved «Ja»; den konkrete støttesituasjonen må vurderes før svar.
- `BEKREFT` - obligatorisk språkbekreftelse.

Svarene fylles først når juridisk og faktisk grunnlag er kontrollert. Denne
arbeidsfilen forhåndsutfyller ikke kvalifiseringssvar.

skal kontrolleres visuelt, men skal ikke brukes som dokumentasjon på rollen som
prosjektleder, organisasjonsrepresentant eller prosjektdeltaker.
