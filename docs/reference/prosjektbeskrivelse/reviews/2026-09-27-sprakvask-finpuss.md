# Språkvask av finpusset tekst 27.09

**Samlet vurdering:** noe KI-preg, mest på tvers av feltene. De enkelte feltene
leste greit hver for seg. Leser man søknaden fra start til slutt, går de samme
grepene igjen.

## Funn på tvers av feltene

| KI-preg | Hvor | Retting |
|---|---|---|
| Samme kontrastfigur, «ikke fordi den er dårligst / ikke fordi løsningen er dårligere» | Innovasjonen, Kunnskapsbehov, Samfunnseffekter (utkast) | Står nå ingen steder. Innovasjonen har «selv om den kan være et godt valg», Kunnskapsbehov har «selv om løsningen er god nok», og Samfunnseffekter er skrevet om |
| Tankestrek-innskudd «– nytt, reparasjon … –» og «– dokumentert, faglig vurdert eller for usikkert –» | Hovedmål, Sammendrag, Innovasjonen | Skrevet som vanlige setninger |
| Kolon brukt som retorisk grep («ulikt sikre: …», «grunnlaget: …», «hypotese: …») | Sammendrag, Innovasjonen, Behov, Samfunnseffekter | Delt i to setninger. Kolon er bare beholdt foran de tre svarene, der det er en ekte oppramsing |
| Fyllord og korte slagordsavslutninger («reelt», «Det er forskningsoppgaven.») | Sammendrag, Innovasjonen | Fjernet eller skrevet om til «det er dette prosjektet skal finne ut» |
| Parallelle avsnitt som begynner med «For kunden … For bransjen … For FoU-miljøer …» | Samfunnseffekter (utkast) | Hvert avsnitt har fått sin egen inngang |
| Tunge nominaliseringer («Relevante forhold knyttet til … skal avgrenses») | Samfunnseffekter | Skrevet om med verb: «Planen for forskningen avgrenser hvordan …» |

## Norm- og kildeport

- **Sluttport:** `pass`.
- **Kilder:** [1] og [12] er uendret, og det er ikke lagt til nye fakta eller tall.
- **«Hvor grensen går, er ikke avklart»:** erstatter «det er ukjent». Den nye formuleringen påstår ikke at ingen vet det.
- **Tilbudsmottakeren:** heter nå «kunden» i Samfunnseffekter, slik resten av den nye teksten gjør.
- **Hovedmål:** lyder nå «caser holdt utenfor utviklingen». Innholdet er det samme som før.
- **Sammendrag:** 1490/1500. Portalens telling er ikke kontrollert. Hvis teksten havner over grensen, er setningen om dagens praksis den første som kan kortes.
