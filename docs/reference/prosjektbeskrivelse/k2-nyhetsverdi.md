# K2 — Nyhetsverdi

**Status:** første røffe utkast · **Sideanslag:** ~2 · **Vurderes under:** Kvalitet  
**Forelder:** `ipn-hovedokument.md` §3 · **Ryggrad:** SoA §11 gap-matrise

## Søknadstekst

VERIFIED er ikke først og fremst en ny app, en ny miljømerking eller en ny kalkulator.
Nyhetsverdien ligger i hvordan flere typer byggdata settes sammen og brukes i selve valget.

Byggeklossene finnes allerede. Det finnes standarder for livsløpsvurdering og livsløpskost.
Det finnes EPD-er, NOBB-data, FDV-data og produktdokumentasjon. Det finnes også metoder for
å veie flere hensyn mot hverandre, som pris, klima, levetid og kvalitet. Dagens verktøy er
likevel i stor grad laget for prosjektering, rapportering eller spesialister.

VERIFIED skal undersøke noe annet: hvordan disse byggeklossene kan bli et enkelt og
forklarbart beslutningsgrunnlag i tilbudsfasen. Prosjektet skal teste om dataene kan gjøres
nyttige for mindre entreprenører og kunder før innkjøpet er låst.

Det nye FoU-laget er derfor ikke selve VIBS-plattformen. VIBS-plattformen er under utvikling
som test- og integrasjonsflate. VERIFIED-laget er forskningsarbeidet: hvordan vekting,
datakvalitet, usikkerhet og beslutningseffekt kan dokumenteres på en måte som tåler kontroll.

Forskningshullet kan beskrives med seks spørsmål:

| Spørsmål | Hva dagens løsninger ofte mangler |
| --- | --- |
| Kan flere datatyper kobles? | Mange verktøy dekker ett eller få spor, særlig klima eller dokumentasjon. |
| Brukes det i tilbudsfasen? | Mye skjer for sent, etter at viktige valg allerede er tatt. |
| Kan SMB bruke det? | Mange løsninger krever spesialistkompetanse. |
| Vises usikkerheten? | Svake eller manglende data skjules ofte i en totalscore. |
| Måles beslutningseffekt? | Det dokumenteres sjelden om verktøyet faktisk endret valget. |
| Håndteres do-not-harm? | Lav CO2 alene kan gi feil valg hvis levetid, vedlikehold og risiko overses. |

VERIFIED skal ikke påstå at alle disse punktene er løst. Prosjektet skal teste dem. Dersom
prosjektet lykkes, får bransjen en modell som viser både beste valg og hvor sikkert grunnlaget
er. Det er viktig for bygg, bank, forsikring og kunder som trenger dokumentasjon de kan stole på.
