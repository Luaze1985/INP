# VISNING.md - IPN VERIFIED

Kort inngang for å vise IPN-mappen fra GitHub på reise eller i møte.

## Åpne først

1. `README.md` - hva repoet er og hva det ikke er.
2. `docs/reference/ipn-prosjektbeskrivelse-utkast.md` - korteste søknadsnære tekst.
3. `docs/reference/state-of-the-art-verified-ipn.md` - FoU-høyde og gap mot state of the art.
4. `docs/reference/ipn-kildebibliotek.md` - kildegrunnlag og statusporter.
5. `CONTEXT.md` - ærlig status og åpne risikoer.

## Si dette høyt

- Dette er IPN-søknadsarbeidet for VERIFIED/VIBS, ikke produktkoden.
- Materialet er egnet som diskusjonsgrunnlag og gjennomgang.
- Det er ikke endelig innsendingsklart før gule kilder er primærverifisert eller formulert med tydelige forbehold.
- SINTEF/fulltekst-sporet er fortsatt relevant for endelig kildeavklaring.

## Trygt å vise

- Søknadsidé, FoU-logikk og metode: `docs/reference/ipn-prosjektbeskrivelse-utkast.md`.
- Kilde- og sannhetsdisiplin: `docs/reference/ipn-kildebibliotek.md`.
- Hvor prosjektet skiller seg fra vanlig bolig-/FDV-digitalisering: `docs/reference/state-of-the-art-verified-ipn.md`.

## Ikke presenter som ferdig

- Ikke si at alle kilder er endelig verifisert.
- Ikke si at søknaden er klar for innsending.
- Ikke bruk parkerte kilder som belegg i muntlig pitch uten forbehold.

## Praktisk GitHub-bruk

Hvis du åpner repoet på mobil eller en fremmed maskin:

1. Start på forsiden av repoet.
2. Åpne `VISNING.md`.
3. Bruk lenkene over som møteagenda.
4. Last ned repoet som ZIP hvis du trenger offline-kopi før tur.
