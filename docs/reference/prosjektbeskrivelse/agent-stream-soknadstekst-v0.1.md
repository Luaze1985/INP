# VERIFIED IPN - agent-stream etter prosa

## Når den kjøres

Streamen starter først når søknadsteksten er skrevet etter blueprinten. Originalteksten låses. Ingen agent overskriver hoveddokumentet direkte.

## Rekkefølge

### 1. Språkvask og av-KI-pass

Kontroller bokmål, klarhet, aktør og handling, KI-preg, anglifisering, gjentakelser og for lange setninger. Bevar avsenderstemme og faglig presisjon. Lever:

- språkvasket kandidat
- kort diagnose
- liste over mulige meningsendringer
- åpne språkspørsmål

### 2. Kilde- og påstandskontroll

Sammenlign hver tallpåstand, årsakspåstand og effektpåstand med kildekritisk kontrolldokument og kanonisk kildedom. Kontroller at gamle kilder ikke er løftet inn som nye fakta. Lever funn uten å oppgradere kildeport.

### 3. Blueprint-review

Kontroller rekkefølgen K1, K3, K2, K4, V1, V2, V3 og Gjennomføring. Kontroller at hvert kapittel har riktig jobb, at hovedsporet er 12.2/12.5, og at teksten sier «skal undersøke, utvikle og måle».

### 4. Kriteriereview

Vurder Kvalitet, Virkninger og Gjennomføring. Finn manglende metode, baseline, målepunkter, DNSH-tiltak, roller, arbeidspakker eller budsjett. Skill mellom kritisk stopp og forbedring.

### 5. Samlet kontroll

Sjekk ordgrense, begrepsbruk mot ordlisten, intern konsistens, gammel/ny versjon, og at ingen kontrollnotater eller URL-er har lekket inn i ren søknadsprosa.

## Sidefiler

Hver runde lagres som egen reviewfil med dato. Hovedteksten endres først etter menneskelig godkjenning. Endringer skal kunne spores tilbake til konkret funn.

## Sluttstatus

Streamen leverer: **klar**, **klar med forbehold** eller **stoppet**. «Klar» betyr ikke at søknaden er godkjent, bare at den passerer intern tekst-, kilde- og kriteriekontroll.
