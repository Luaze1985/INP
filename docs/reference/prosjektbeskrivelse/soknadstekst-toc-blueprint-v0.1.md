# VERIFIED IPN - søknadstekst
## TOC og skrive-blueprint v0.1

Ikke prosa. Ikke hoveddokument. Styrer rekkefølge og ordvalg.

1. **Bakgrunn - K1:** Problemet i tilbudsfasen: spredte data, SMB-rammer og valg som påvirker pris, levetid, klima og risiko.
2. **Mål - K3:** Ett hovedmål og seks FoU-spørsmål. Skill mellom kjent kunnskap og det VERIFIED skal undersøke.
3. **Hva finnes - K2:** Standarder, produktdata og spesialistverktøy. Vis gapet: tilbudsfase, SMB, flere hensyn, usikkerhet og beslutningseffekt.
4. **Metode - K4:** Data, vekting, usikkerhet, modellvalg og pilot. Skriv «skal teste».
5. **Bærekraft - V1:** Hovedspor 12.2, eventuelt 12.5. Mål CO2, materialbruk, levetid, reparasjon, ombruk og utskifting.
6. **Sikkerhet - V2:** Lav pris eller lav CO2 skal ikke overstyre levetid, egnethet, dokumentasjon, data eller personvern.
7. **Virkninger - V3:** Nytte for entreprenør og kunde. Bank/forsikring er sekundært og krever konkret pilot.
8. **Gjennomføring:** Arbeidspakker, tidsplan, roller, budsjett, sammenligningsgrunnlag og støttegrad.

**Språkregel:** Korte setninger, konkret handling, ett begrep om gangen. Kildekontroll hører til i kontrolldokumentet.
