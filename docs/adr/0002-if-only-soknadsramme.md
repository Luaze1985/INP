# ADR 0002: IF-only søknadsramme for VERIFIED

**Status:** Besluttet 2026-08-27.

VERIFIEDs neste søknadskandidat avgrenses til industriell forskning i AP1–AP3. AP4–AP6 og eksperimentell utvikling tas ut i stedet for å bli omklassifisert som industriell forskning. Prosjektrammen er 16,0 MNOK, med 8,0 MNOK søkt støtte og 8,0 MNOK egenfinansiering. Dette gjør prosjektets FoU-kjerne og økonomi enklere og mer etterprøvbar.

Kandidatteksten samler prosjektbeskrivelse og grovsortert økonomi i ett dokument. Den skal ha én kort kostnadsbærertabell, mens leverandørdetaljer og referanseaktører holdes i intern aktørmatrise slik at kostnader ikke dobbelttelles.

Banker og finansaktører er utenfor prosjektets IF-only-avgrensning og skal ikke omtales som aktørgruppe, partner, leverandør, referanseaktør eller brukergruppe.
