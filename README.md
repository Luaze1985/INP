# ipn-verified

IPN-søknaden **VERIFIED** til Norges forskningsråd — eget prosjekt, skilt ut fra VIBS-produktappen `vibs-boligpass/` 2026-06-28.

Dette repoet inneholder søknadstekst, kilder, kildeverifisering, styringsdokumenter og den offentlige statussiden for VERIFIED (`site/web/`). Det inneholder **ikke** produktkode (plattform, UI, pilot) — det ligger fortsatt i `vibs-boligpass/`.

## Start her

1. `VISNING.md` — kort inngang for å vise materialet på reise eller i møte.
2. `AGENTS.md` — regler, roller, kilde-/sannhetsprinsipper.
3. `CONTEXT.md` — hvor søknaden står nå og hva som gjenstår.
4. `INDEX.yml` — full filoversikt.
5. `IPN-FLYTTES.md` — status på utskillingen (hva er kopiert, hva gjenstår).
